# Source-private color-baseline diagnostic contract — 9 November 2026

Status: local exploratory development analysis, fixed before measuring any color-baseline endpoint outcome. No new publisher transfer, model training, source label acquisition, or clinical claim.

Inputs: exactly the PR72 69 distinct annotated runs and their recorded one positive + one native neighbouring explicitly negative image, four development examinations Galar 23/25/29/30. Verify individual source-PNG SHA256 and bytes against the existing private frozen support manifest; use only already-retained original PNGs from official fitting sources. Do not substitute approximate frames or unknown labels.

Feature: apply EXIF transpose, convert to RGB, resize full field with PIL bicubic to 160x160 without cropping. Within a circular central aperture of radius 70 pixels centered at (79.5,79.5), retain pixels whose sum of R+G+B is at least 45 on byte scale (a black-border rejection). For each retained pixel, compute (R-G)/(R+G+20.0), clipped to [-1,1]. One image receives the mean of these values as its transparent red-versus-green score. Higher score means more red-biased. This is a fixed hand-designed indicator, not a learned probability or a specific blood detector. No outcome-dependent threshold, crop, feature weights, or parameter search. For empty eligible masks, stop rather than silently impute.

Paired endpoint: positive-score minus negative-score; order correct if >0, incorrect if <0, tie worth 0.5. Report exact integer counts and macro-average across the four exams, plus pooled counts (descriptive), including 21 singleton runs. Independently replay the calculation from source pixels using separately written code. Report per-exam failures and the caveat that annotated runs are not lesions/patients; four inspected exams are insufficient for population inference.
