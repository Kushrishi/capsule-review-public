## Endpoints and controls

Count distinct positive annotation runs, positive images separately, and run lengths1–5,6–25,26+. Break runs at every source gap. Missing/nonbinary labels fail closed. Zero-positive recalls are undefined.

Primary mechanistic control: independently permute the fixed scores inside each of the original K floor-partitioned chronology bins and apply the original maximum/earliest-tie selector. This preserves one selection per bin, score multiset, bin boundaries and workload, while removing local score-position alignment. Use10,000 repetitions with NumPy PCG64 SeedSequence([20261106,exam,percent,1]). Sample winner locations from the exact permutation distribution: if m maxima tie in a bin of L positions, the earliest maximum has probability C(L-j-1,m-1)/C(L,m) at local j. Also compute geometry-only independent uniform-one-per-bin expectations exactly (and simulations), so tie bias is visible. Unique-max bins make these controls identical.

For every run compute the exact chance of at least one selected positive position as1-product over intersecting bins of(1-bin hit probability). Sum these probabilities for expected distinct-run recall; expected positive-image count sums per-position selection probabilities. Verify simulated means against analytic expectations with Monte Carlo standard errors. Report control2.5/97.5 percentiles and observed-minus-control means, randomized upper-tail (1+count(null>=observed))/(R+1), and paired repetition-level macro contrasts. These are conditional reference distributions, not patient confidence intervals or causal proof.

Sensitivity:100 fixed midpoint phases (phase=(j+0.5)/100, j=0..99), each exact-K systematic sampling floor((i+phase)*N/K). Compare real score-bin to phase distributions; do not choose a best phase. A second control uses all nonzero circular shifts of scores within16 fixed coarse chronology blocks and reruns score-bin: sample1,000 fixed draws, SeedSequence([20261106,exam,percent,2]), shifting each block independently by an offset from1..length-1. This preserves coarse score domain and local score autocorrelation; the block boundary discontinuity and exchangeability assumptions limit interpretation. No block/window search. No extra global permutation is needed because it destroys the chronology being controlled.

## Aggregation and uncertainty
Principal cross-exam result is the arithmetic mean of positive-examination run-recall contrasts; never pool image counts as the principal estimator. Show both examinations and their difference/range. Two selected development cases cannot support reliable population confidence intervals: report the exact two-exam bootstrap support (three possible macro values with weights.25/.5/.25) only as a descriptive instability check, with no generalization claim. Monte Carlo precision is separate from cross-examination uncertainty. Run-wise short/long contrasts are descriptive, not independent lesion trials. Do not convert contrasts into a causal percentage of benefit.

## Interpretation
Positive conditional contrasts support local score information beyond this geometry on these examined cases only. Null or negative contrasts weaken that explanation. Randomization validity assumes conditional exchangeability, which capsule chronology does not guarantee. Neither result upgrades the model, establishes pathology causation, adjudicated lesion recall, reader time or clinical safety. Preserve all historical negative findings.
