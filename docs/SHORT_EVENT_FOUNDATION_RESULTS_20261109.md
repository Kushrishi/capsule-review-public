## Decision and next experimental investment

The strengthened cohort reveals a useful conditional ranking effect that sparse, imbalanced support did not establish. It does **not** establish that insufficient examples were the primary limitation: classification data effects are mixed/negative and singleton transfer remains unreliable. Representation, local context, objective/reference mismatch and examination-specific appearance remain plausible; none is uniquely proven. The fixed guard also fails to improve10% coverage, so a simple geometry constraint is not a sufficient remedy.

**Single next investment:** one fixed frozen-representation comparison on this secured69-run/four-examination cohort, with the current compact CNN retained as control and singleton consistency required before downstream advancement. A concrete low-acquisition-cost candidate is the already recorded576-D MobileNetV3-Small representation with one fixed linear head and the unchanged CE/ranking comparison; preserve its earlier negative image-retrieval results. Reverify pixel/feature mapping, preprocessing and pinned backbone weights before use. This new local-pair/representation comparison has not run here and must be separately frozen. It tests representation under fixed new support rather than repeating an architecture sweep or purchasing more pairs.
