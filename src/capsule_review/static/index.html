Export includes bookmarked frames and frames with saved notes or labels, with an illustrated HTML file and JSON record. It is not a complete-examination report.

Select Verify evidence to check the actual export against its saved history, image checksums and complete local study manifest. The result counts omitted interval interiors and compares ordinal image positions at equal workload. This is not pathology detection or a clinical assessment.

Export review keeps bookmarked/noted images and interval boundaries only. Export full spans produces a separate, potentially large ZIP with every imported image inside marked spans (plus other saved frames). It is verified before being sent and must be kept private. Neither export proves which original-video images were captured, viewed or diagnosed.

Reference labels are separate from model output. Train and install an optional local baseline to run region classification. No medically trained weights are bundled. Prediction scores are not assumed to be calibrated probabilities.

This local app has no user authentication. Keep it on localhost; do not expose it to the internet. Workspace files are not encrypted.
